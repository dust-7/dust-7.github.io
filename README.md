# dust-7.github.io

My portfolio site.

### Local setup
1. Clone repo with `git clone https://github.com/dust-7/dust-7.github.io.git`.
2. Install NPM packages with `npm i`.
3. Create `.env.local` file in the root folder with the following variables:
   - VITE_API_BASE_URL

### Commonly used scripts
- `npm run dev` - starts a local instance accessible at http://localhost:5173/
- `npm test` - runs unit tests via vitest with browser mode
